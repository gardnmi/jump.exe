# jump.exe asset provenance

The game has an original generic developer character and original environment
art. It does not bundle reference screenshots, gameplay footage, or website images.
The third-party movement sound effects are documented below.

## Cover art

[`docs/story-preview.png`](../docs/story-preview.png) is promotional cover art
generated with the built-in OpenAI image-generation tool. The supplied Jump King
cover guided the composition; the game's character atlas guided the developer's
outfit and palette. The [generation prompt](../docs/story-preview.prompt.txt) is
included. The previous five-stage gameplay illustration is preserved as
[`docs/stage-preview.png`](../docs/stage-preview.png).

## Character and environment

`omarchy-developers.png` is the original 1447×1087 RGBA atlas generated for this
project using OpenAI's image generation tool on September 28, 2026. The source
image is preserved unchanged. Its [prompt](omarchy-developers.prompt.txt) is
included in the source repository. The generic developer wears a jade hoodie and
cream beanie; the caretaker carries a laptop. Neither portrays a real person.

All window interiors, solid terrain, terminals, hardware, pills, furniture,
creatures, and environmental animation are original code drawings in
`src/jump_exe/`. The character and rooms are composed on native pixel grids and
scaled with nearest-neighbor filtering.

The visual guide is [Omarchy](https://omarchy.org/) and its
[Osaka Jade theme](https://github.com/basecamp/omarchy/tree/master/themes/osaka-jade).
CaskaydiaMono Nerd Font is supplied by the system package
`ttf-cascadia-mono-nerd`; no font file is bundled.

## Soundtrack

These five tracks were supplied by the project owner, with source metadata
crediting **gardnmi**. The supplied MP3 filenames identified usesuno.com. They
were compressed to stereo Opus at approximately 80 kbit/s, with cover art removed.
Metadata alone is not a separate licensing claim; see [asset terms](LICENSE.md).

| Stage | Track | File |
| --- | --- | --- |
| Denial | Silent Pixel Realm | `silent-pixel-realm.opus` |
| Anger | 警告信号 (Warning Signal) | `warning-signal.opus` |
| Bargaining | Searching for a Signal | `searching-for-a-signal.opus` |
| Depression | Desolate Arpeggios | `desolate-arpeggios.opus` |
| Acceptance | Trionfo Sereno | `trionfo-sereno.opus` |

Encode an owner-supplied track with:

```sh
ffmpeg -i input.mp3 -map 0:a:0 -vn -map_metadata -1 \
  -c:a libopus -b:a 80k -vbr on -application audio output.opus
```

## Effects

`sfx/jump.wav`, `sfx/land.wav`, and `sfx/heavy_land.wav` are the original movement
clips selected for the prototype at the project owner's request. Version 0.1.0
replaced them with synthesized effects; the original files have been restored
unchanged, including their sample rates and levels.

They came from the public
[JumpKingAtHome audio directory](https://github.com/senweim/JumpKingAtHome/tree/6c3d1a7ba9246181b89e67b1f4857df99c85fa01/Audio/King/Land)
at revision `6c3d1a7ba9246181b89e67b1f4857df99c85fa01`, a community recreation of
Nexile's Jump King. Original-game provenance has not been independently
authenticated. These are third-party clips; no license file was present in the
source repository, and they are not covered by this project's MIT code license.

| Bundled file | Original filename | SHA-256 |

| `sfx/jump.wav` | `king_jump.wav` | `95fd68fd3856f613805bbd3a129271efe10fb49c746a05befcd90d5f01c15375` |
